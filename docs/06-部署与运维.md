# 部署与运维

## 环境要求

### 必需软件

| 软件 | 版本 | 用途 |
|------|------|------|
| PHP | 7.4+ | 运行后端程序 |
| MySQL | 5.7+ | 数据存储 |
| Apache/Nginx | - | Web服务器 |

### 推荐环境

- **操作系统**: Windows Server 2016+ / Windows 10+
- **Web服务器**: Apache 2.4+ with mod_rewrite
- **PHP扩展**: mysqli, curl, json, mbstring

## 安装步骤

### 1. 部署代码

```bash
# 将代码复制到Web目录
cd d:\xampp\htdocs
git clone <repository-url> CarAlert
cd CarAlert
```

### 2. 配置数据库

系统支持双数据库架构，需要配置两个独立的数据库：

```sql
-- 创建广场停车场数据库
CREATE DATABASE IF NOT EXISTS bs_park_client_1
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

-- 创建地下车库数据库
CREATE DATABASE IF NOT EXISTS bs_park_client_2
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

-- 在两个数据库中执行迁移脚本
USE bs_park_client_1;
SOURCE database/migration_blacklist.sql;

USE bs_park_client_2;
SOURCE database/migration_blacklist.sql;

-- 初始化车库信息（在两个数据库中都执行）
USE bs_park_client_1;
INSERT INTO p_garage (garage_id, garage_name) VALUES (1, '广场停车场');

USE bs_park_client_2;
INSERT INTO p_garage (garage_id, garage_name) VALUES (2, '星光大厦地下车库');
```

### 3. 配置连接信息

复制并编辑 `.env` 文件：

```bash
cd d:\xampp\htdocs\CarAlert
copy .env.example .env
notepad .env
```

编辑 `.env` 文件，配置双数据库连接：

```ini
# 数据库1：广场停车场
DB_HOST1=127.0.0.1
DB_PORT1=3306
DB_USER1=root
DB_PASS1=your_password
DB_NAME1=bs_park_client_1

# 数据库2：星光大厦地下车库
DB_HOST2=127.0.0.1
DB_PORT2=3306
DB_USER2=root
DB_PASS2=your_password
DB_NAME2=bs_park_client_2

# 企业微信Webhook配置
WECHAT_WEBHOOK_TEST=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=test_key
WECHAT_WEBHOOK_PROD=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=prod_key
```

### 4. 启动守护进程

系统需要运行两个独立的守护进程，分别监控两个数据库：

```cmd
cd d:\xampp\htdocs\CarAlert\daemon

# 启动广场停车场守护进程
start_daemon_plaza.bat

# 启动地下车库守护进程
start_daemon_garage.bat
```

## 开机自启动配置

### 方法：Windows任务计划程序

系统提供了两个独立的启动脚本，分别用于两个车库：

#### 步骤1：安装广场停车场守护进程

以**管理员身份**运行：

```cmd
cd d:\xampp\htdocs\CarAlert\daemon
install_task_plaza.bat
```

#### 步骤2：安装地下车库守护进程

以**管理员身份**运行：

```cmd
cd d:\xampp\htdocs\CarAlert\daemon
install_task_garage.bat
```

#### 步骤3：验证任务

```cmd
# 查看广场停车场任务
schtasks /query /tn "CarAlert_Daemon_Plaza"

# 查看地下车库任务
schtasks /query /tn "CarAlert_Daemon_Garage"
```

#### 卸载任务

```cmd
# 卸载广场停车场任务
schtasks /delete /tn "CarAlert_Daemon_Plaza" /f

# 卸载地下车库任务
schtasks /delete /tn "CarAlert_Daemon_Garage" /f
```

## 故障排查

### 问题1：守护进程无法启动

**现象**：运行启动脚本后闪退

**排查步骤**：
1. 检查PHP是否在环境变量中
   ```cmd
   php -v
   ```
2. 检查.env文件是否存在且配置正确
   ```cmd
   type d:\xampp\htdocs\CarAlert\.env
   ```
3. 检查数据库连接（测试数据库1）
   ```cmd
   php -r "require_once 'api/DatabaseHelper.php'; \$conn = DatabaseHelper::getConnection(1); var_dump(\$conn);"
   ```
4. 检查数据库连接（测试数据库2）
   ```cmd
   php -r "require_once 'api/DatabaseHelper.php'; \$conn = DatabaseHelper::getConnection(2); var_dump(\$conn);"
   ```

### 问题2：收不到通知

**现象**：日志显示发送成功，但企业微信没收到

**排查步骤**：
1. 检查Webhook配置
   ```ini
   # 在.env文件中检查
   WECHAT_WEBHOOK_TEST=...
   WECHAT_WEBHOOK_PROD=...
   ```
2. 测试通知（全部车库）
   ```
   在浏览器访问：
   http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test&dbIndex=0
   ```
3. 测试通知（仅广场）
   ```
   在浏览器访问：
   http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test&dbIndex=1
   ```
4. 测试通知（仅地下车库）
   ```
   在浏览器访问：
   http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test&dbIndex=2
   ```
5. 检查企业微信群是否存在
6. 检查机器人是否被移除
7. 查看详细日志
   ```cmd
   type d:\xampp\htdocs\CarAlert\daemon\daemon_plaza.log
   type d:\xampp\htdocs\CarAlert\daemon\daemon_garage.log
   ```

### 问题3：数据库连接失败

**现象**：日志显示"数据库连接失败"

**排查步骤**：
1. 检查MySQL服务是否运行
   ```cmd
   net start mysql
   ```
2. 检查配置信息
3. 测试连接（数据库1）
   ```cmd
   mysql -h 127.0.0.1 -P 3306 -u root -p bs_park_client_1
   ```
4. 测试连接（数据库2）
   ```cmd
   mysql -h 127.0.0.1 -P 3306 -u root -p bs_park_client_2
   ```

### 问题4：守护进程频繁重启

**现象**：PID文件不断变化

**原因**：
- 可能同时运行了多个实例
- 数据库连接不稳定

**解决**：
```cmd
# 1. 停止所有PHP进程
taskkill /F /IM php.exe

# 2. 删除PID文件
del d:\xampp\htdocs\CarAlert\daemon\daemon_plaza.pid
del d:\xampp\htdocs\CarAlert\daemon\daemon_garage.pid

# 3. 重新启动
cd d:\xampp\htdocs\CarAlert\daemon
start_daemon_plaza.bat
start_daemon_garage.bat
```

### 问题5：无法区分是哪个车库的通知

**现象**：收到通知但不知道来自哪个车库

**解决**：
- 新的通知格式已包含车库前缀，如 `[广场停车场]` 或 `[星光大厦地下车库]`
- 检查守护进程是否使用正确的启动脚本（start_daemon_plaza.bat 或 start_daemon_garage.bat）

## 安全建议

### 1. 配置文件保护

```cmd
# 移除其他用户的读取权限
icacls d:\xampp\htdocs\CarAlert\.env /deny Everyone:R
```

### 2. 数据库安全

- 使用独立的数据库用户
- 限制用户权限（只读或读写）
- 定期更换密码
- 两个数据库使用不同的密码

### 3. 日志清理

```cmd
# 定期清理广场停车场日志（超过30天）
forfiles /p d:\xampp\htdocs\CarAlert\daemon /m daemon_plaza.log /d -30 /c "cmd /c del @path"

# 定期清理地下车库日志（超过30天）
forfiles /p d:\xampp\htdocs\CarAlert\daemon /m daemon_garage.log /d -30 /c "cmd /c del @path"
```

### 4. 备份策略

- 每日自动备份两个数据库
- 每周完整备份代码
- 备份存储到异地
