# 部署与运维

## 环境要求

### 必需软件

| 软件 | 版本 | 用途 |
|------|------|------|
| PHP | 7.4+ | 运行后端程序 |
| MySQL | 5.7+ | 数据存储 |
| Apache/Nginx | - | Web服务器 |

### 推荐环境

- **操作系统**: Windows Server 2016+ / Windows 10+
- **Web服务器**: Apache 2.4+ with mod_rewrite
- **PHP扩展**: mysqli, curl, json, mbstring

## 安装步骤

### 1. 部署代码

```bash
# 将代码复制到Web目录
cd d:\xampp\htdocs
git clone <repository-url> CarAlert
cd CarAlert
```

### 2. 配置数据库

```sql
-- 创建数据库（如不存在）
CREATE DATABASE IF NOT EXISTS car_alert 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 执行迁移脚本
SOURCE database/migration_blacklist.sql;
```

### 3. 配置连接信息

编辑 `daemon/config.php`：

```php
// 数据库配置
define('DB_HOST', '127.0.0.1');
define('DB_PORT', 3306);
define('DB_USER', 'root');
define('DB_PASS', 'your_password');
define('DB_NAME', 'car_alert');

// 企业微信Webhook配置
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);
define('WECHAT_WORK_WEBHOOK', 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=测试key');
```

### 4. 启动守护进程

```cmd
cd d:\xampp\htdocs\CarAlert\daemon
start_daemon.bat
```

## 开机自启动配置

### 方法：Windows任务计划程序

#### 步骤1：创建启动脚本

文件已存在：`daemon/start_daemon_hidden.vbs`

```vbs
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "d:\xampp\htdocs\CarAlert\daemon\start_daemon.bat", 0, False
Set WshShell = Nothing
```

#### 步骤2：安装任务

以**管理员身份**运行：

```cmd
cd d:\xampp\htdocs\CarAlert\daemon
install_task_en.bat
```

或手动创建：
```cmd
schtasks /create /tn "CarAlert_Daemon" /tr "d:\xampp\htdocs\CarAlert\daemon\start_daemon_hidden.vbs" /sc onstart /ru SYSTEM /rl highest /f
```

#### 步骤3：验证任务

```cmd
schtasks /query /tn "CarAlert_Daemon"
```

#### 卸载任务

```cmd
schtasks /delete /tn "CarAlert_Daemon" /f
```

## 故障排查

### 问题1：守护进程无法启动

**现象**：运行 start_daemon.bat 后闪退

**排查步骤**：
1. 检查PHP是否在环境变量中
   ```cmd
   php -v
   ```
2. 检查配置文件是否存在
   ```cmd
   type d:\xampp\htdocs\CarAlert\daemon\config.php
   ```
3. 检查数据库连接
   ```cmd
   php -r "new mysqli('127.0.0.1', 'root', 'password', 'car_alert', 3306);"
   ```

### 问题2：收不到通知

**现象**：日志显示发送成功，但企业微信没收到

**排查步骤**：
1. 检查Webhook配置
   ```php
   // 在浏览器访问
   http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test
   ```
2. 检查企业微信群是否存在
3. 检查机器人是否被移除
4. 查看详细日志
   ```cmd
   type d:\xampp\htdocs\CarAlert\daemon\daemon.log
   ```

### 问题3：数据库连接失败

**现象**：日志显示"数据库连接失败"

**排查步骤**：
1. 检查MySQL服务是否运行
   ```cmd
   net start mysql
   ```
2. 检查配置信息
3. 测试连接
   ```cmd
   mysql -h 127.0.0.1 -P 3306 -u root -p
   ```

### 问题4：守护进程频繁重启

**现象**：PID文件不断变化

**原因**：
- 可能同时运行了多个实例
- 数据库连接不稳定

**解决**：
```cmd
# 1. 停止所有PHP进程
taskkill /F /IM php.exe

# 2. 删除PID文件
del d:\xampp\htdocs\CarAlert\daemon\daemon.pid

# 3. 重新启动
cd d:\xampp\htdocs\CarAlert\daemon
start_daemon.bat
```

## 安全建议

### 1. 配置文件保护

```cmd
# 移除其他用户的读取权限
icacls d:\xampp\htdocs\CarAlert\daemon\config.php /deny Everyone:R
```

### 2. 数据库安全

- 使用独立的数据库用户
- 限制用户权限（只读或读写）
- 定期更换密码

### 3. 日志清理

```cmd
# 定期清理日志（超过30天）
forfiles /p d:\xampp\htdocs\CarAlert\daemon /m *.log /d -30 /c "cmd /c del @path"
```

### 4. 备份策略

- 每日自动备份数据库
- 每周完整备份代码
- 备份存储到异地
