# 守护进程详解

## 什么是守护进程？

守护进程（Daemon）是一个**后台运行的程序**，它会持续运行并执行特定任务。在 CarAlert 系统中，守护进程负责实时监控车辆抓拍记录。

## 双守护进程架构

系统采用**两个独立守护进程**的架构，分别监控两个停车场系统：

## 类比理解

想象守护进程就像两个**24小时值班的保安**：
- 保安A：在广场停车场，每隔1秒查看一次监控屏幕（轮询数据库1）
- 保安B：在地下车库，每隔1秒查看一次监控屏幕（轮询数据库2）
- 发现可疑人员（拉黑车牌）立即报警（发送企业微信通知）
- 发现重要访客（关注车牌）立即通知（发送企业微信提醒）

## 守护进程启动脚本说明

### 1. start_daemon_plaza.bat - 广场停车场守护进程

**特点**：
- 连接数据库1（DB_HOST, DB_PORT, DB_USER, DB_PASS, DB_NAME）
- 日志文件：`daemon_plaza.log`
- PID文件：`daemon_plaza.pid`
- 通知前缀：`[广场]`

**使用方法**：
```cmd
cd daemon
start_daemon_plaza.bat
```

### 2. start_daemon_garage.bat - 星光大厦地下车库守护进程

**特点**：
- 连接数据库2（DB2_HOST, DB2_PORT, DB2_USER, DB2_PASS, DB2_NAME）
- 日志文件：`daemon_garage.log`
- PID文件：`daemon_garage.pid`
- 通知前缀：`[星光大厦地下车库]`

**使用方法**：
```cmd
cd daemon
start_daemon_garage.bat
```

### 3. start_daemon.bat - 旧版启动脚本（兼容）

**注意**：仅用于单数据库模式，连接数据库1。

## 守护进程参数解析

守护进程支持从命令行获取数据库索引和名称：

```
notify_daemon.php <数据库索引> <车库名称>
```

**示例**：
```bash
# 启动广场停车场守护进程
php notify_daemon.php 1 广场停车场

# 启动地下车库守护进程
php notify_daemon.php 2 星光大厦地下车库
```

## 关键代码解析

### 1. 启动初始化

```php
// 确定连接哪个数据库（从命令行参数获取）
$dbIndex = $argv[1] ?? 1; // 1=广场, 2=地下车库
$garageNameForNotify = $argv[2] ?? ''; // 通知前缀名称

// 加载 .env 配置
loadEnv(__DIR__ . '/../.env');

// 连接指定数据库
$connection = DatabaseHelper::getConnection($dbIndex);

// 获取车库信息（用于通知前缀）
$garageInfo = getGarageInfo($connection);
if (empty($garageNameForNotify) &amp;&amp; !empty($garageInfo['garage_name'])) {
    $garageNameForNotify = $garageInfo['garage_name'];
}

// 获取最后处理的记录ID
$lastProcessedId = checkNewData($connection);
writeLog("初始 last_record_id: {$lastProcessedId}");

// 加载关注/拉黑列表
$watchPlates = getWatchPlates($connection);
$blacklistPlates = getBlacklistPlates($connection);
writeLog("关注车牌数: " . count($watchPlates) . ", 拉黑车牌数: " . count($blacklistPlates));
```

### 2. 检测新数据

```php
function checkNewData($conn) {
    $sql = "SELECT MAX(id) as max_id FROM p_distinguish_log";
    $result = $conn-&gt;query($sql);
    $row = $result-&gt;fetch_assoc();
    return $row['max_id'] ?? 0;
}
```

**原理**：获取表中最大的ID，新记录的ID一定比这个大。

### 3. 主循环逻辑

```php
while (true) {
    // 检查是否需要退出
    if (!file_exists($pidFile)) {
        writeLog("PID文件已删除，守护进程即将退出");
        break;
    }
    
    // 获取当前最大ID
    $currentLastId = checkNewData($connection);
    
    // 发现新数据
    if ($currentLastId &gt; $lastProcessedId) {
        writeLog("检测到新的车辆抓拍记录 (ID: {$currentLastId})");
        
        // 获取新记录详情
        $newRecords = getRecordsAfterId($connection, $lastProcessedId);
        
        // 处理每条记录
        foreach ($newRecords as $record) {
            processRecord($record, $garageNameForNotify);
        }
        
        // 更新已处理ID
        $lastProcessedId = $currentLastId;
        
        // 更新 p_update_flag 表
        updateLastRecordId($connection, $lastProcessedId);
    }
    
    // 等待1秒
    sleep(POLL_INTERVAL);
}
```

### 4. 记录处理流程

```php
function processRecord($record, $garageNameForNotify) {
    $plateNumber = $record['plate_number'];
    
    // 1. 检查是否是拉黑车牌（优先处理）
    if (isset($blacklistPlates[$plateNumber])) {
        writeLog("拉黑车牌预警触发: {$plateNumber}");
        sendBlacklistAlert($record, $blacklistPlates[$plateNumber], $garageNameForNotify);
    }
    
    // 2. 检查是否是关注车牌
    if (in_array($plateNumber, $watchPlates)) {
        writeLog("关注车牌提醒触发: {$plateNumber}");
        sendWatchNotification($record, $garageNameForNotify);
    }
}
```

**注意**：通知发送时会添加车库名称前缀，例如 `[广场] 拉黑车牌预警`。

## 常见问题

### Q1: 两个守护进程可以同时运行吗？

A: **可以！** 这是系统推荐的方式。两个守护进程独立运行，互不干扰。

### Q2: 如何区分是哪个车库发送的通知？

A: 通知标题会包含车库名称前缀，例如：
- `[广场] 拉黑车牌预警`
- `[星光大厦地下车库] 关注车牌提醒`

### Q3: 守护进程占用多少资源？

A: 非常少。每个守护进程主要是每秒一次的数据库查询，查询的是索引字段，性能开销极小。

### Q4: 如果数据库连接断开怎么办？

A: 守护进程会自动重连。如果重连失败，会记录错误日志并退出。

### Q5: 如何停止某个守护进程？

A: 有两种方式：
1. 在运行窗口按 `Ctrl+C`
2. 删除对应的 PID 文件（`daemon_plaza.pid` 或 `daemon_garage.pid`）

### Q6: 可以只运行一个守护进程吗？

A: **可以！** 如果只需要监控一个车库，只运行对应的守护进程即可。

### Q7: 旧版启动脚本还能用吗？

A: 可以！`start_daemon.bat` 仍然有效，它会连接数据库1（广场停车场）。

## 性能优化

1. **增量查询**：只查询ID大于 `last_record_id` 的记录
2. **内存缓存**：关注和拉黑列表缓存在内存中，避免频繁查询
3. **连接复用**：数据库连接不频繁断开重连
4. **批量处理**：一次获取所有新记录，减少查询次数
5. **独立进程**：两个守护进程独立运行，资源不冲突
