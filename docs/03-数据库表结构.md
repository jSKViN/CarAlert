# 数据库表结构

## 表关系图

```
┌──────────────────────┐
│      p_garage        │ ← 车库信息表（识别不同车库）
│   garage_id: 1/2     │
└──────────┬───────────┘
           │
           │ 关联
           ▼
┌──────────────────────┐
│  p_distinguish_log   │ ← 车辆抓拍记录（数据来源）
│  车辆抓拍记录表       │
└──────────┬───────────┘
           │
           │ 触发检测
           ▼
┌──────────────────────┐     ┌──────────────────────┐

│    关注车牌表         │     │    拉黑车牌表         │

           ▼                            ▼
┌──────────────────────┐     ┌──────────────────────┐

└──────────────────────┘     └──────────────────────┘
```

## 详细表结构

### 1. p_garage（车库信息表）

**说明**：识别不同的车库系统，用于区分数据来源。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `garage_id` | INT | 车库ID，主键 |
| `garage_name` | VARCHAR(100) | 车库名称 |

**示例数据**：
```sql
-- 广场停车场
INSERT INTO p_garage (garage_id, garage_name) VALUES (1, '广场停车场');

-- 地下车库
INSERT INTO p_garage (garage_id, garage_name) VALUES (2, '星光大厦地下车库');
```

---

### 2. p_distinguish_log（车辆抓拍记录表）

**说明**：摄像头抓拍车辆后，系统自动将数据写入此表。这是整个系统的数据源。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `create_time` | TIMESTAMP | 抓拍时间 |
| `real_time_info` | JSON | 实时信息（车型、图片URL等） |
| `access_info` | JSON | 通行信息（费用等） |
| `lane_id` | INT | 车道ID |

**示例数据**：
```sql
INSERT INTO p_distinguish_log (plate_number, create_time, real_time_info, access_info, lane_id)
VALUES (
    '川G9A502',
    NOW(),
    '{"carType":"轿车","fullPictureUrl":""}',
    '{"fee":0}',
    1
);
```

---

### 3. p_watch_plates（关注车牌表）

**说明**：存储需要特别关注的车辆车牌，当这些车辆被拍到时会发送提醒通知。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号（唯一） |
| `garage_id` | INT | 车库ID，NULL表示全部车库 |
| `remark` | VARCHAR(100) | 备注说明 |
| `is_active` | TINYINT(1) | 是否启用：0-禁用，1-启用 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**示例操作**：
```sql
-- 添加关注车牌（指定车库）
INSERT INTO p_watch_plates (plate_number, garage_id, remark)
VALUES ('渝A205HW', 1, '重要客户车辆');

-- 添加关注车牌（全部车库）
INSERT INTO p_watch_plates (plate_number, garage_id, remark)
VALUES ('渝A67890', NULL, 'VIP车辆（全部车库）');

-- 查询所有启用的关注车牌
SELECT * FROM p_watch_plates WHERE is_active = 1;

-- 禁用关注车牌
UPDATE p_watch_plates SET is_active = 0 WHERE plate_number = '渝A205HW';
```

---

### 4. p_blacklist_plates（拉黑车牌表）

**说明**：存储被拉黑的车辆车牌，当这些车辆被拍到时会发送预警通知。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `garage_id` | INT | 车库ID，NULL表示全部车库 |
| `reason` | VARCHAR(500) | 拉黑原因 |
| `operator` | VARCHAR(50) | 操作人 |
| `blacklist_type` | TINYINT(1) | 拉黑类型：1-临时，2-永久 |
| `start_time` | TIMESTAMP | 拉黑开始时间 |
| `end_time` | TIMESTAMP | 拉黑结束时间（永久为NULL） |
| `is_active` | TINYINT(1) | 是否生效：0-已解除，1-生效中 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**唯一索引**：

| 索引名 | 字段组合 | 说明 |
|--------|----------|------|
| `uk_plate_active` | `plate_number + is_active + garage_id` | 确保同一车牌同一状态同一车库只有一条记录 |

> **注意**：唯一索引确保同一车牌在同一状态下（生效中/已解除）在同一车库只有一条记录。garage_id为NULL时表示全部车库。

**示例操作**：
```sql
-- 添加永久拉黑（指定车库）
INSERT INTO p_blacklist_plates (plate_number, garage_id, reason, blacklist_type, operator)
VALUES ('川G9A502', 1, '违规车辆', 2, 'admin');

-- 添加永久拉黑（全部车库）
INSERT INTO p_blacklist_plates (plate_number, garage_id, reason, blacklist_type, operator)
VALUES ('渝A11111', NULL, '黑名单车辆（全部车库）', 2, 'admin');

-- 添加临时拉黑（30天）
INSERT INTO p_blacklist_plates (plate_number, garage_id, reason, blacklist_type, operator, end_time)
VALUES ('渝A12345', 2, '临时管控', 1, 'admin', DATE_ADD(NOW(), INTERVAL 30 DAY));

-- 解除拉黑
UPDATE p_blacklist_plates SET is_active = 0 WHERE plate_number = '川G9A502';

-- 查询生效中的拉黑
SELECT * FROM p_blacklist_plates WHERE is_active = 1;
```

---

### 5. p_watch_log（关注操作日志表）

**说明**：记录关注车牌的所有操作（添加、启用、禁用、删除），用于审计追溯。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `garage_id` | INT | 车库ID |
| `action_type` | VARCHAR(20) | 操作类型：ADD-添加，ENABLE-启用，DISABLE-禁用，DELETE-删除 |
| `reason` | VARCHAR(500) | 原因/备注 |
| `operator` | VARCHAR(50) | 操作人 |
| `old_data` | JSON | 操作前的数据 |
| `new_data` | JSON | 操作后的数据 |
| `created_at` | TIMESTAMP | 操作时间 |

**示例数据**：
```sql
-- 查询某车牌的操作历史
SELECT * FROM p_watch_log WHERE plate_number = '渝A205HW' ORDER BY created_at DESC;
```

---

### 6. p_blacklist_log（拉黑操作日志表）

**说明**：记录拉黑车牌的所有操作（添加、解除、更新），用于审计追溯。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `garage_id` | INT | 车库ID |
| `action_type` | VARCHAR(20) | 操作类型：ADD-添加，REMOVE-解除，UPDATE-更新 |
| `reason` | VARCHAR(500) | 原因/备注 |
| `operator` | VARCHAR(50) | 操作人 |
| `old_data` | JSON | 操作前的数据 |
| `new_data` | JSON | 操作后的数据 |
| `created_at` | TIMESTAMP | 操作时间 |

**示例数据**：
```sql
-- 查询某车牌的拉黑历史
SELECT * FROM p_blacklist_log WHERE plate_number = '川G9A502' ORDER BY created_at DESC;
```

---

### 7. p_update_flag（更新标记表）

**说明**：守护进程使用此表记录最后处理的记录ID，确保不遗漏数据。每个数据库有独立的p_update_flag表。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 固定为1 |
| `last_record_id` | BIGINT | 最后处理的distinguish_id |
| `last_update_time` | TIMESTAMP | 最后更新时间 |
| `notify_count` | INT | 已发送通知次数 |

**说明**：守护进程启动时会读取此表的 `last_record_id`，然后只处理ID大于此值的新记录。

## 常用查询

### 查询今日抓拍的关注车牌
```sql
SELECT d.*, w.remark, g.garage_name
FROM p_distinguish_log d
JOIN p_watch_plates w ON d.plate_number = w.plate_number
LEFT JOIN p_garage g ON w.garage_id = g.garage_id
WHERE DATE(d.create_time) = CURDATE()
AND w.is_active = 1;
```

### 查询今日抓拍的拉黑车牌
```sql
SELECT d.*, b.reason, b.blacklist_type, g.garage_name
FROM p_distinguish_log d
JOIN p_blacklist_plates b ON d.plate_number = b.plate_number
LEFT JOIN p_garage g ON b.garage_id = g.garage_id
WHERE DATE(d.create_time) = CURDATE()
AND b.is_active = 1;
```

### 统计各类型拉黑数量
```sql
SELECT 
    g.garage_name,
    b.blacklist_type,
    COUNT(*) as count
FROM p_blacklist_plates b
LEFT JOIN p_garage g ON b.garage_id = g.garage_id
WHERE b.is_active = 1
GROUP BY g.garage_name, b.blacklist_type;
```

### 查询即将过期的临时拉黑
```sql
SELECT b.*, g.garage_name
FROM p_blacklist_plates b
LEFT JOIN p_garage g ON b.garage_id = g.garage_id
WHERE b.blacklist_type = 1
AND b.is_active = 1
AND b.end_time <= DATE_ADD(NOW(), INTERVAL 3 DAY);
```

### 查询全部车库的车牌
```sql
-- 全部车库的关注车牌
SELECT * FROM p_watch_plates WHERE garage_id IS NULL AND is_active = 1;

-- 全部车库的拉黑车牌
SELECT * FROM p_blacklist_plates WHERE garage_id IS NULL AND is_active = 1;
```

## 索引说明

为了提高查询性能，各表都建立了适当的索引：

- `p_distinguish_log`: `plate_number`, `create_time`
- `p_watch_plates`: `plate_number`, `garage_id` (复合唯一索引)
- `p_blacklist_plates`: `plate_number`, `garage_id`, `is_active`, `end_time`
- `p_watch_log`: `plate_number`, `garage_id`, `action_type`, `created_at`
- `p_blacklist_log`: `plate_number`, `garage_id`, `action_type`, `created_at`
