# 数据库表结构

## 表关系图

```
┌──────────────────────┐

           ▼
```

## 详细表结构

### 1. p_distinguish_log（车辆抓拍记录表）

**说明**：摄像头抓拍车辆后，系统自动将数据写入此表。这是整个系统的数据源。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | BIGINT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `create_time` | TIMESTAMP | 抓拍时间 |
| `real_time_info` | JSON | 实时信息（车型、图片URL等） |
| `access_info` | JSON | 通行信息（费用等） |
| `lane_id` | INT | 车道ID |

**示例数据**：
```sql
INSERT INTO p_distinguish_log (plate_number, create_time, real_time_info, access_info, lane_id)
VALUES (
    '川G9A502',
    NOW(),
    '{"carType":"轿车","fullPictureUrl":""}',
    '{"fee":0}',
    1
);
```

---

### 2. p_watch_plates（关注车牌表）

**说明**：存储需要特别关注的车辆车牌，当这些车辆被拍到时会发送提醒通知。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号（唯一） |
| `remark` | VARCHAR(100) | 备注说明 |
| `is_active` | TINYINT(1) | 是否启用：0-禁用，1-启用 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**示例操作**：
```sql
-- 添加关注车牌
INSERT INTO p_watch_plates (plate_number, remark)
VALUES ('渝A205HW', '重要客户车辆');

-- 查询所有启用的关注车牌
SELECT * FROM p_watch_plates WHERE is_active = 1;

-- 禁用关注车牌
UPDATE p_watch_plates SET is_active = 0 WHERE plate_number = '渝A205HW';
```

---

### 3. p_blacklist_plates（拉黑车牌表）

**说明**：存储被拉黑的车辆车牌，当这些车辆被拍到时会发送预警通知。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `reason` | VARCHAR(500) | 拉黑原因 |
| `operator` | VARCHAR(50) | 操作人 |
| `blacklist_type` | TINYINT(1) | 拉黑类型：1-临时，2-永久 |
| `start_time` | TIMESTAMP | 拉黑开始时间 |
| `end_time` | TIMESTAMP | 拉黑结束时间（永久为NULL） |
| `is_active` | TINYINT(1) | 是否生效：0-已解除，1-生效中 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**示例操作**：
```sql
-- 添加永久拉黑
INSERT INTO p_blacklist_plates (plate_number, reason, blacklist_type, operator)
VALUES ('川G9A502', '违规车辆', 2, 'admin');

-- 添加临时拉黑（30天）
INSERT INTO p_blacklist_plates (plate_number, reason, blacklist_type, operator, end_time)
VALUES ('渝A12345', '临时管控', 1, 'admin', DATE_ADD(NOW(), INTERVAL 30 DAY));

-- 解除拉黑
UPDATE p_blacklist_plates SET is_active = 0 WHERE plate_number = '川G9A502';

-- 查询生效中的拉黑
SELECT * FROM p_blacklist_plates WHERE is_active = 1;
```

---

### 4. p_watch_log（关注操作日志表）

**说明**：记录关注车牌的所有操作（添加、启用、禁用、删除），用于审计追溯。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `action_type` | VARCHAR(20) | 操作类型：ADD-添加，ENABLE-启用，DISABLE-禁用，DELETE-删除 |
| `reason` | VARCHAR(500) | 原因/备注 |
| `operator` | VARCHAR(50) | 操作人 |
| `old_data` | JSON | 操作前的数据 |
| `new_data` | JSON | 操作后的数据 |
| `created_at` | TIMESTAMP | 操作时间 |

**示例数据**：
```sql
-- 查询某车牌的操作历史
SELECT * FROM p_watch_log WHERE plate_number = '渝A205HW' ORDER BY created_at DESC;
```

---

### 5. p_blacklist_log（拉黑操作日志表）

**说明**：记录拉黑车牌的所有操作（添加、解除、更新），用于审计追溯。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 主键，自增ID |
| `plate_number` | VARCHAR(20) | 车牌号 |
| `action_type` | VARCHAR(20) | 操作类型：ADD-添加，REMOVE-解除，UPDATE-更新 |
| `reason` | VARCHAR(500) | 原因/备注 |
| `operator` | VARCHAR(50) | 操作人 |
| `old_data` | JSON | 操作前的数据 |
| `new_data` | JSON | 操作后的数据 |
| `created_at` | TIMESTAMP | 操作时间 |

**示例数据**：
```sql
-- 查询某车牌的拉黑历史
SELECT * FROM p_blacklist_log WHERE plate_number = '川G9A502' ORDER BY created_at DESC;
```

---

### 6. p_update_flag（更新标记表）

**说明**：守护进程使用此表记录最后处理的记录ID，确保不遗漏数据。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 固定为1 |
| `last_record_id` | BIGINT | 最后处理的distinguish_id |
| `last_update_time` | TIMESTAMP | 最后更新时间 |
| `notify_count` | INT | 已发送通知次数 |

**说明**：守护进程启动时会读取此表的 `last_record_id`，然后只处理ID大于此值的新记录。

## 常用查询

### 查询今日抓拍的关注车牌
```sql
SELECT d.*, w.remark 
FROM p_distinguish_log d
JOIN p_watch_plates w ON d.plate_number = w.plate_number
WHERE DATE(d.create_time) = CURDATE()
AND w.is_active = 1;
```

### 查询今日抓拍的拉黑车牌
```sql
SELECT d.*, b.reason, b.blacklist_type
FROM p_distinguish_log d
JOIN p_blacklist_plates b ON d.plate_number = b.plate_number
WHERE DATE(d.create_time) = CURDATE()
AND b.is_active = 1;
```

### 统计各类型拉黑数量
```sql
SELECT 
    blacklist_type,
    COUNT(*) as count
FROM p_blacklist_plates
WHERE is_active = 1
GROUP BY blacklist_type;
```

### 查询即将过期的临时拉黑
```sql
SELECT *
FROM p_blacklist_plates
WHERE blacklist_type = 1
AND is_active = 1
AND end_time <= DATE_ADD(NOW(), INTERVAL 3 DAY);
```

## 索引说明

为了提高查询性能，各表都建立了适当的索引：

- `p_distinguish_log`: `plate_number`, `create_time`
- `p_watch_plates`: `plate_number` (唯一索引)
- `p_blacklist_plates`: `plate_number`, `is_active`, `end_time`
- `p_watch_log`: `plate_number`, `action_type`, `created_at`
- `p_blacklist_log`: `plate_number`, `action_type`, `created_at`
