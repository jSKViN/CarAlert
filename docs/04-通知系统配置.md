# 通知系统配置

## 概述

CarAlert 支持多种通知渠道，目前主要使用**企业微信 Webhook** 进行通知。

## 企业微信 Webhook 配置

### 配置文件位置

`daemon/config.php`

### 配置项说明

```php
// 测试环境（开发测试用）
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);
define('WECHAT_WORK_WEBHOOK', 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=测试key');

// 正式环境（生产环境用）
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', false);
define('WECHAT_WORK_WEBHOOK_PROD', 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=正式key');
```

### 环境切换

#### 场景1：仅测试环境（当前配置）
```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);      // 开启测试
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', false); // 关闭正式
```
**效果**：只发送到测试群

#### 场景2：仅正式环境（上线后）
```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', false);     // 关闭测试
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', true);  // 开启正式
```
**效果**：只发送到正式群

#### 场景3：双环境同时发送
```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);      // 开启测试
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', true);  // 开启正式
```
**效果**：同时发送到测试群和正式群

## 如何获取 Webhook Key

### 步骤1：创建企业微信群
1. 打开企业微信
2. 创建一个群聊（或选择已有群）
3. 群成员需要包含"群机器人"

### 步骤2：添加群机器人
1. 在群聊中点击右上角"..."
2. 选择"群机器人"
3. 点击"添加机器人"
4. 选择"新创建一个机器人"
5. 输入机器人名称（如：车辆监控预警）

### 步骤3：获取 Webhook 地址
1. 创建完成后，会显示 Webhook 地址
2. 复制地址，格式如：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
3. 将 `key=` 后面的部分替换到配置文件中

### 步骤4：验证配置
1. 访问测试页面：
   ```
   http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test
   ```
2. 检查企业微信群是否收到测试消息


### 关键日志说明

| 日志 | 含义 |
|------|------|
| `通知目标：测试环境` | 当前只发送到测试环境 |
| `通知目标：正式环境` | 当前只发送到正式环境 |
| `通知目标：测试环境、正式环境` | 同时发送到两个环境 |
| `企业微信[测试环境]...已发送` | 测试环境发送成功 |
| `企业微信[正式环境]...已发送` | 正式环境发送成功 |

## 常见问题

### Q: 为什么收不到通知？

**检查步骤**：
1. 检查 `NOTIFY_WECHAT_WORK_WEBHOOK` 是否为 `true`
2. 检查 Webhook URL 是否正确
3. 查看 `daemon.log` 是否有发送记录
4. 检查企业微信群是否还存在
5. 检查机器人是否被移除

### Q: 如何测试通知是否正常？

**方法1：API测试**
```
http://localhost/CarAlert/api/wechat_work_webhook_notify.php?action=test
```

**方法2：模拟抓拍**
```sql
-- 插入测试记录
INSERT INTO p_distinguish_log (plate_number, create_time, real_time_info, access_info, lane_id)
VALUES ('川G9A502', NOW(), '{"carType":"轿车"}', '{"fee":0}', 1);

-- 更新标记触发检测
UPDATE p_update_flag SET last_record_id = (SELECT MAX(id) FROM p_distinguish_log);
```

### Q: 正式环境和测试环境可以同时开启吗？

**可以**。修改配置：
```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', true);
```

### Q: 通知有延迟吗？

**正常情况下**：
- 守护进程1秒轮询一次
- 网络正常时，通知秒级到达
- 总延迟通常在1-3秒内

## 安全注意事项

1. **保护 Webhook Key**：不要泄露到公共代码仓库
2. **定期更换**：建议定期更换 Webhook Key
3. **IP白名单**：企业微信支持设置IP白名单，建议配置
4. **测试环境隔离**：测试和正式环境使用不同的群

## 其他通知渠道（已禁用）

系统还支持以下通知渠道，但当前已禁用：

### 钉钉
```php
define('NOTIFY_DINGTALK', false);
define('DINGTALK_WEBHOOK', 'https://oapi.dingtalk.com/robot/send?access_token=xxx');
```

### Server酱
```php
define('NOTIFY_SERVERCHAN', false);
define('SERVERCHAN_SENDKEY', 'YOUR_SENDKEY');
```

如需启用，将 `false` 改为 `true` 并配置相应参数。
