# CarAlert 系统架构

## 概述

CarAlert 是一个车辆监控预警系统，支持双数据库架构（广场停车场 + 地下车库），通过独立守护进程实时监听两个数据库的车辆抓拍记录，对关注车牌和拉黑车牌进行实时通知。

## 核心组件

### 1. 数据库表

| 表名 | 作用 | 数据来源 |
|------|------|----------|
| `p_garage` | 车库信息表 | 识别不同车库系统 |
| `p_distinguish_log` | 存储车辆抓拍记录 | 摄像头系统自动写入 |
| `p_watch_plates` | 存储关注车牌列表 | 管理员手动添加 |
| `p_blacklist_plates` | 存储拉黑车牌列表 | 管理员手动添加 |
| `p_blacklist_log` | 拉黑操作日志 | 系统自动记录 |
| `p_watch_log` | 关注操作日志 | 系统自动记录 |
| `p_update_flag` | 更新标记表 | 守护进程使用 |

### 2. 双守护进程

**文件**: `daemon/notify_daemon.php`

**启动方式**:
- 广场停车场: `daemon/start_daemon_plaza.bat`
- 地下车库: `daemon/start_daemon_garage.bat`

**核心功能**:
- 每1秒轮询检查 `p_distinguish_log` 表
- 发现新记录后比对车牌
- 匹配则调用通知接口，带车库前缀标识

**工作流程**:
```
启动 → 加载配置 → 连接指定数据库 → 获取最后处理ID
  ↓
循环检测 ← 发现新记录 → 比对车牌 → 发送通知（带车库标识）
  ↓
更新最后处理ID → 继续循环
```

### 3. 通知系统

**文件**: `api/wechat_work_webhook_notify.php`

**支持的环境**:
- 广场停车场通知
- 地下车库通知

**通知格式**:
```
[广场] 关注车牌通知: 渝A205HW
[地下车库] 拉黑预警: 川G9A502
```

### 4. 数据库连接管理

**文件**: `api/DatabaseHelper.php`

**功能**:
- 支持连接两个独立数据库
- 通过 `dbIndex` 参数切换数据库 (1=广场, 2=地下车库)
- 支持"全部车库"操作模式

## 关键配置

```php

DB_PORT1=3306
DB_USER1=root
DB_PASS1=password
DB_NAME1=bs_park_client

DB_HOST2=127.0.0.1
DB_PORT2=3306
DB_USER2=root
DB_PASS2=password
DB_NAME2=bs_park_client
```

### 轮询间隔

```php
define('POLL_INTERVAL', 1);  // 1秒检测一次
```

### 通知开关

```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);      // 启用企业微信通知
define('NOTIFY_DINGTALK', false);                  // 钉钉（已禁用）
define('NOTIFY_SERVERCHAN', false);                // Server酱（已禁用）
```

## 性能考虑

1. **轮询间隔1秒**：平衡实时性和系统负载
2. **数据库连接复用**：减少连接开销
3. **增量查询**：只查询新记录，不扫描全表
4. **内存缓存**：关注和拉黑列表缓存在内存中
5. **独立守护进程**：两个数据库互不影响

## 扩展性

- 支持多数据库（可扩展至更多车库）
- 支持多种通知渠道（企业微信、钉钉、Server酱）
- 模块化设计，易于添加新功能
- 支持"全部车库"统一管理操作
