# CarAlert 系统架构

## 概述

CarAlert 是一个车辆监控预警系统，通过守护进程实时监听车辆抓拍记录，对关注车牌和拉黑车牌进行实时通知。

## 核心组件

### 1. 数据库表

| 表名 | 作用 | 数据来源 |
|------|------|----------|
| `p_distinguish_log` | 存储车辆抓拍记录 | 摄像头系统自动写入 |
| `p_watch_plates` | 存储关注车牌列表 | 管理员手动添加 |
| `p_blacklist_plates` | 存储拉黑车牌列表 | 管理员手动添加 |
| `p_blacklist_log` | 拉黑操作日志 | 系统自动记录 |
| `p_watch_log` | 关注操作日志 | 系统自动记录 |
| `p_update_flag` | 更新标记表 | 守护进程使用 |

### 2. 守护进程

**文件**: `daemon/notify_daemon.php`

**核心功能**:
- 每1秒轮询检查 `p_distinguish_log` 表
- 发现新记录后比对车牌
- 匹配则调用通知接口

**工作流程**:
```
启动 → 加载配置 → 连接数据库 → 获取最后处理ID
  ↓
循环检测 ← 发现新记录 → 比对车牌 → 发送通知
  ↓
更新最后处理ID → 继续循环
```

### 3. 通知系统

**文件**: `api/wechat_work_webhook_notify.php`

**支持的环境**:
- 测试环境（开发测试用）
- 正式环境（生产环境用）

**配置方式**:
```php
// 测试环境
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);
define('WECHAT_WORK_WEBHOOK', 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=测试key');

// 正式环境
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', false);  // 默认关闭
define('WECHAT_WORK_WEBHOOK_PROD', 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=正式key');
```

## 数据流向

```
摄像头抓拍
    ↓
写入 p_distinguish_log
    ↓

    ↓
提取车牌号
    ↓
┌──────────────┐    ┌──────────────┐
│  是否在关注列表? │    │  是否在拉黑列表? │
└──────┬───────┘    └──────┬───────┘
       │                    │
       ▼                    ▼
   发送关注通知          发送拉黑预警
```

## 关键配置

### 轮询间隔
```php
define('POLL_INTERVAL', 1);  // 1秒检测一次
```

### 通知开关
```php
define('NOTIFY_WECHAT_WORK_WEBHOOK', true);      // 测试环境
define('NOTIFY_WECHAT_WORK_WEBHOOK_PROD', false); // 正式环境
define('NOTIFY_DINGTALK', false);                  // 钉钉（已禁用）
define('NOTIFY_SERVERCHAN', false);                // Server酱（已禁用）
```

## 性能考虑

1. **轮询间隔1秒**：平衡实时性和系统负载
2. **数据库连接复用**：减少连接开销
3. **增量查询**：只查询新记录，不扫描全表
4. **内存缓存**：关注和拉黑列表缓存在内存中

## 扩展性

- 支持多数据库（主库+从库）
- 支持多种通知渠道（企业微信、钉钉、Server酱）
- 模块化设计，易于添加新功能
